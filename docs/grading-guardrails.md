# Grading guardrails (three axes)

Full research: `docs/research-sg-sea-frame-grading-ingest.md` §E.

| Mistake | Rule |
| --- | --- |
| Pretty paint → `PASS_VISUAL` | Cosmetics never clear structural concerns |
| Rare / prestige brand → safe | Brand seed never sets inspection outcome |
| `P*` ↔ `F*` | Preservation effort ≠ market desirability |
| `F5` → build-ready | Build requires `PASS_VISUAL` + no unresolved critical flags |
| UCI / ISO sticker → this frame is sound | Claims are standards evidence only |
| Tap-test ring → carbon cleared | Label “Screen”; unresolved impact → HOLD |
| Complete-bike ask as bare FS | Match `forkInclusion`; haircut bundled extras |
| Steel surface rust → automatic REJECT | Perforation / structural rust fails; surface feeds P-class |
| Folder hinge damage ignored | Hinge is structure on Tern / Dahon / Brompton |
| Letter grade `F` = value class `F1` | Different vocabularies — never collapse |

Money stays integer SGD cents. Cost floor = `prepared_cost / (1 - margin - fee)`.
